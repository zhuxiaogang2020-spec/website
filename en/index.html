About the Project

The Mushroom Harvesting Robot is an ongoing R&D project focused on automated mushroom picking.

By combining vision detection, path planning, and robotic arm control, our goal is to achieve precise harvesting, improve agricultural automation, and reduce manual labor costs.

The project is currently in the concept phase, with the robotic arm still under development but the core technical roadmap already defined.
